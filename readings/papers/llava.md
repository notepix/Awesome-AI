# LLaVA：把视觉 token 接入语言模型并学会按图像回答

> Haotian Liu、Chunyuan Li、Qingyang Wu、Yong Jae Lee，*Visual Instruction Tuning*，NeurIPS 2023；核对 [arXiv v2 全文](https://arxiv.org/pdf/2304.08485v2)。本文定位原始 LLaVA，不把 LLaVA-1.5、NeXT 等后续结构视作原论文配置。先修：[CLIP](clip.md)、[LLaMA](llama.md)、[H04 连接器](../../docs/02-perception-language/h-multimodal-vlm.md#h04)。

## 对齐空间不等于能够对话

CLIP 的图像表示擅长与文本向量匹配，语言模型则接收一串词嵌入并预测下一 token。两者的维度、训练任务与表示分布不同。LLaVA 使用投影连接器把视觉特征映射到语言模型的隐藏空间，再通过图文对齐与视觉指令学习，让语言模型在视觉输入条件下生成回答。

论文还研究怎样把图像的文字描述、物体位置等信息转成视觉指令数据。数据构造模型生成的问答不等于无误标注，需要意识到错误可能被后续模型继承。

## 输入张量与条件生成

图像编码器将一张图转成 $N_v$ 个视觉特征 $Z_v\in\mathbb R^{N_v\times d_v}$。原始版本采用线性投影，将其变成 $H_v=Z_vW\in\mathbb R^{N_v\times d}$，$d$ 与语言 embedding 宽度一致。然后将视觉 token 与文本 token 按规定的对话模板组织，输入自回归语言模型。

损失只计算需要模型回答的 token：

$$L=-\sum_{t\in\mathcal A}\log p_\theta(y_t\mid H_v,\text{instruction},y_{<t}),$$

$\mathcal A$ 为助手回答位置集合。图像 patch 本身不是此处词表交叉熵的目标。模板、角色边界和 EOS 都属于训练输入语义，而非可随意替换的界面文字。

## 一个连接器与序列例子

教学设两块视觉特征为 $Z_v=\begin{bmatrix}1&0\\0&1\end{bmatrix}$，投影 $W=\begin{bmatrix}1&2&0\\0&1&3\end{bmatrix}$，则视觉 token 为 $(1,2,0)$ 和 $(0,1,3)$，宽度从2变3。它们成为语言模型能处理的连续向量，但“宽度相同”只是能相加/拼接的前提，不是语义对齐已完成的证据。

若指令含3个文本 token，回答含2个 token，忽略角色标记时总长度为7。前5个位置提供条件，后2个位置作为回答标签。假设回答正确 token 概率为0.8、0.6，求和损失 $-\ln0.8-\ln0.6\approx0.7340$，回答 token 平均损失约0.3670。若误把全部7个位置都做同样监督，训练任务已经改变。

一个完整测试可用图片中“红球在蓝盒左侧”的教学场景：先问物体，再问颜色，最后问左右关系。前两题正确但第三题错误，说明全局识别与关系理解不同；不能只展示一段流畅描述就确认视觉推理成功。

## 两阶段训练与推理

原文 §4 描述先进行特征对齐：冻结视觉编码器和语言模型，主要训练投影；再进行视觉指令微调，保持视觉编码器冻结，训练投影和语言模型。应按具体论文版本和实验设置确认可训练模块。后来的多层连接器与高分辨率拼接不属于本文原始线性投影配置。

推理先完成图像预处理和视觉编码，再进行文本自回归生成。多轮对话需要正确保留图像相关状态与上下文，不能在每轮无意重复插入同一视觉序列造成长度错误。图像缩放、裁剪和位置细节会改变可见信息；模型无法恢复预处理阶段被裁掉的物体。

常见幻觉包括识别出图中不存在的物体、凭常识补全颜色或数量、忽略用户指令中的限定范围。视觉输入存在不意味着回答全部由图像支持：语言先验可能压过视觉证据。

## 源码与本地实验

[Transformers 导读](../projects/transformers.md) 实际阅读的是 decoder-only 模型，可用于理解语言前向、标签移位和生成；processor、视觉特征选择与 projector 是阅读 LLaVA 实现时还需单独追踪的部分。[multimodal 实验](../../labs/multimodal/README.md) 用小样本说明双塔对齐与评价，没有实现完整 LLaVA 条件生成，不能称为复现论文大模型训练。再与 [CLIP](clip.md) 对照，画出“匹配得分”与“条件文本生成”两条不同输出链。

## 从回答掩码追踪到第一个生成 token

将上例输入记作 $[v_1,v_2,q_1,q_2,q_3,a_1,a_2]$，这里的视觉符号代表连续嵌入，而非词表编号。按常见自回归标签约定，原位置标签是 $[-100,-100,-100,-100,-100,a_1,a_2]$；随后损失内部将 logits 去掉最后一位、标签去掉第一位。因此，$q_3$ 位置的输出预测 $a_1$，$a_1$ 位置的输出预测 $a_2$。若在数据准备时也提前移位一次，就会错过首个回答 token，形成二次移位错误。这个展开是教学序列，真实实现还包含角色标记、结束符和图像占位展开。

只屏蔽条件位置的标签，并不等于把条件位置从注意力中屏蔽。回答仍须访问图像和问题；若把两种 mask 混用，损失虽然可以下降，模型却可能主要学习语言先验。第一阶段即使语言模型参数被冻结，也要保留从回答损失穿过语言模型到连接器的梯度路径；对整个语言前向使用无梯度上下文，会同时切断连接器所需的学习信号。

## 用受控对照检查视觉依赖

对于“红球在蓝盒左侧”的场景，可设计三组教学对照：保持问题不变并左右翻转图像；保持图像不变，分别询问球与盒子的相对位置；保持整体布置不变，只替换球的颜色。若答案始终重复同一句，应先检查视觉输入是否实际进入模型，再分析数据捷径与关系推理能力，不能立即归因于某个网络模块。

这类检查需要预先定义物体、颜色、关系三个答案字段，分别统计正确性；流畅度与事实正确性单列。再加入图像中不存在的物体，检查系统是否能表达无法确认。对照实验能定位某类失败，但少数人工场景不能给出总体可靠性保证，生成问答的自动评审也不能替代图像证据核对。

## 自测与答案

1. **线性投影后维度一致是否足够？** 不够，还需学习把视觉语义映射到语言模型可利用的表示分布。
2. **为什么只监督助手 token？** 指令和图像是条件，目标是学会回答；把条件也当回答标签会改变训练目标。
3. **流畅的图像描述为何仍可能幻觉？** 自回归语言先验能生成合理但图中不存在的内容，需要针对图像事实单独评估。
