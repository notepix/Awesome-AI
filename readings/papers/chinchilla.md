# Chinchilla：固定计算预算下，模型与数据怎样一起增长

> Jordan Hoffmann 等，*Training Compute-Optimal Large Language Models*，NeurIPS 2022；核对 [arXiv v1 全文](https://arxiv.org/pdf/2203.15556v1)。先修：[A17 优化](../../docs/01-foundations/a-math-statistics-optimization.md#a17)、[D14 规模规律](../../docs/01-foundations/d-deep-learning.md#d14)、[GPT-3](gpt3.md)。

## 首先明确优化问题

问题不是“参数越多是否更强”，而是给定训练 FLOPs，参数量 $N$ 与训练 token 数 $D$ 应如何分配。大模型每处理一个 token 更贵，所以相同预算下增加参数常意味着减少数据。若模型未充分训练，继续放大它可能不如让较小模型读更多数据。

训练计算最优、推理成本最优、固定延迟最优是不同目标。原论文主要研究第一种，不能把其经验配比直接当作所有生产场景的规定。需要服务大量请求时，训练时多花一点成本换较小模型，可能有另一种经济最优点。

## 损失模型与约束推导

论文 §3.3 使用可解释的参数形式近似损失：

$$L(N,D)=E+\frac{A}{N^\alpha}+\frac{B}{D^\beta},\qquad C\approx6ND.$$

$E$ 表示不可通过这两个规模项继续消除的极限项，$A,B,\alpha,\beta$ 需从实验拟合。$6ND$ 是稠密 Transformer 训练计算的近似，不包含所有硬件效率与系统开销。

固定 $C$ 后代入 $D=C/(6N)$，得 $L(N)=E+AN^{-\alpha}+B(6N/C)^\beta$。令对 $N$ 的导数为零：

$$\alpha AN^{-\alpha}=\beta BD^{-\beta}.$$

这表示最优点两种资源的边际贡献平衡，并不是两项数值必然相等。整理可得 $N_{opt}\propto C^{\beta/(\alpha+\beta)}$、$D_{opt}\propto C^{\alpha/(\alpha+\beta)}$。当拟合指数接近时，两者随预算近似同速增长。

## 一个可核算的玩具预算

教学设 $C/6=ND=100$，简化为 $L-E=1/N+1/D$，即 $A=B=1$、$\alpha=\beta=1$。选择 $(N,D)=(20,5)$，超额损失为 $0.05+0.2=0.25$；选择 $(10,10)$ 则为0.2；选择 $(5,20)$ 又回到0.25。最优是平衡点10与10。

若预算扩大4倍，使 $ND=400$，最优变成 $(20,20)$；不是把参数增加4倍而保持数据不动。这个手算展示约束优化的形状，但这里 N、D 是无量纲教学单位，不能当成真实模型的参数/token 配比。

再设数据更难获得，真实有效 token 增长小于重复训练 token 数。此时简单地把重复 token 填进同一条幂律会高估信息收益；需要重新验证拟合范围与数据分布。规模定律是经验模型，外推时应携带误差和假设。

## 训练、推理与本地学习连接

模型训练仍是自回归交叉熵；变化是训练前的资源分配，而不是推理时新增层。推理只需最终模型，较小参数量通常影响权重内存与每 token 计算，但长上下文 KV 内存仍需单独核算。

在 [minigpt 实验](../../labs/minigpt/README.md) 中，适合做教学级“固定处理 token 数”或“近似固定 FLOPs”对照，记录参数数目、序列长度、更新次数、验证损失。不能用几分钟的小模型曲线声称复现论文大规模指数；可以练习绘制损失—计算图并解释混杂因素。进一步阅读 [LLaMA](llama.md)，理解训练预算与推理实用性的不同侧重点。

失败条件包括损失拟合超出范围、语料质量变化、重复样本占比过高、训练未收敛、计算估算漏掉注意力长序列项，以及只按墙钟时间比较不同硬件。FLOPs、耗时、费用和能耗各有含义，应分别报告。

## 规模规律的拟合与外推该如何理解

计算最优曲线不是从单个大模型的结果直接读出的。需要训练一组覆盖不同参数规模与训练长度的模型，观察同一预算附近损失最低的配置，再拟合预算增长时最优点如何移动。若实验网格没有覆盖真实最优区，拟合结果可能只是边界上最好的候选，并不代表连续空间中的最优解。

损失函数中的常数项也值得关注。当数据量与参数量很大时，两个可改善项越来越小，拟合的不可约项会显著影响推断出的斜率。噪声、验证集分布差异和训练未完成都可能改变拟合。报告一条光滑曲线时，应同时记住它来自有限实验，不是对每个预算都实际训练并观察了最优模型。

近似计算量与实际耗时之间还隔着硬件利用率。一个更宽但更短的模型可能更适合特定矩阵运算，另一个配置虽有更少浮点运算却需要更多通信或内存访问。因此按固定浮点运算得到的资源分配，不一定使单台机器上的时间最短。若目标是费用，应把训练时长、设备单价和失败重跑成本纳入另一层分析。

验证损失下降与下游任务提升也不是完全等价。某些任务对罕见知识、长推理链或特定格式更敏感，平均语言建模损失可能掩盖这些变化。合理的阅读顺序是先确认预训练损失规律，再检查论文选择的下游任务是否支持预期迁移，不能直接用下游单个分数反推一个普遍规模指数。

教学实验可以选择三种小模型宽度，各训练几个预先规定的步数，画出验证损失与近似计算量。由于小实验范围窄，应把输出称为曲线观察，保留多个候选并讨论误差，而不要拟合出许多小数位后宣称精确规律。学习价值在于明白怎样提出预算约束、设置比较网格和区分内插与外推，而不是制造一个看起来专业的幂律公式。

## 自测与答案

1. **固定 C 时把 N 加倍会怎样？** 按近似 $C=6ND$，D 要减半，因此不能只享受容量增加而忽略数据减少。
2. **为什么最优不是 N 与 D 数值相等？** 系数、指数和单位不同；相等只发生在特意对称的教学例子中。
3. **训练最优一定最适合在线服务吗？** 不一定，服务请求量、延迟和硬件内存会引入推理成本约束。
