# BERT：双向上下文、掩码预测与任务适配

> Jacob Devlin、Ming-Wei Chang、Kenton Lee、Kristina Toutanova，*BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding*，NAACL 2019；阅读 [arXiv v1 全文](https://arxiv.org/pdf/1810.04805v1)，章节与表号以此版本为准。先修：[Transformer](transformer.md)、[F08 预训练目标](../../docs/02-perception-language/f-nlp-transformers-llms.md#f08)、[D11 迁移学习](../../docs/01-foundations/d-deep-learning.md#d11)。

## 双向表示解决什么问题

同一个词在不同语境中含义不同，表示应依赖两侧上下文。但若直接让一个双向模型看到目标词本身再预测它，模型可以复制输入。BERT 通过遮住部分 token，把“结合前后语境理解”变为可监督的预测问题，并把预训练参数迁移到分类、句子关系和抽取式问答。

这里的“双向”是同一层注意力可联合读取两侧位置，不只是把两个单向语言模型的最终向量拼接。它也不等于能直接左到右生成长答案：预训练条件与自回归模型不同。

## 输入与两个训练目标

输入典型形式为 `[CLS] A [SEP] B [SEP]`。每个位置由 token embedding、segment embedding、position embedding 相加，得到 $X\in\mathbb R^{B\times T\times d}$；编码器输出同形状 $H$。MLM 预测头映射为 $B\times T\times |V|$ 的词表 logits，只在被选中的预测位置计算损失。

原文选择 15% 的 token 作为预测目标；其中 80% 换成 `[MASK]`，10% 换成随机词，10% 保留原词。**被选中集合**与**被换成 MASK 集合**不同。保留原词的位置仍参与 MLM 损失，这样模型不能仅凭看见特殊标记才准备预测。

$$L_{MLM}=-\sum_{i\in S}\log p_\theta(x_i\mid\widetilde x),\qquad
L_{NSP}=-\log p_\theta(c\mid H_{[CLS]}).$$

NSP 判断 B 是否为 A 的真实后续句；它是原论文的预训练设计，而不是自然语言语义相似度的通用定义。句子分类可用 `[CLS]` 表示；序列标注用各 token 表示；抽取式问答为每个位置产生起点、终点分数。

## 一个掩码例子与损失

教学分词序列为“我 / 把 / 钱 / 存入 / 银行 / 了”。选中“银行”，改成 `[MASK]`；模型能同时看到“存入”和“了”。若词表中“银行、河岸、学校”的预测概率为 $(0.7,0.2,0.1)$，该位置损失是 $-\ln0.7\approx0.3567$。若标签错误地写成 `[MASK]`，模型学到的是输出遮罩符号，训练任务已被改坏。

再选中“钱”但保留输入原词，该位置仍以“钱”为标签；它提供较容易的训练信号，不能因此把所有未遮罩位置都算进损失。若有两个选中位置，常见实现取二者损失平均；padding 与特殊 token 的处理应明确记录。

用于问答时，假设段落有效 token 为“北京 / 是 / 中国 / 首都”，起点与终点都应落在“北京”。若起点概率为 0.8、终点概率为 0.6，单独求和的边界损失是 $-\ln0.8-\ln0.6\approx0.734$。这是新的任务头与微调监督，不是 MLM 的直接输出。

## 训练、使用和误解

预训练先学习一般表示；微调把整个编码器与任务头共同优化，数据量小时学习率和 epoch 数会影响过拟合。推理不必给分类输入添加 `[MASK]`，因为输出来自任务头。不同 checkpoint 的 tokenizer、词表、大小写约定、特殊 token ID 不能随意混用。

原始 BERT 的最大长度、绝对位置 embedding 与 WordPiece 切分会影响长文档和词级标签对齐。对分裂成多个子词的一个词，要先决定只监督首子词还是传播标签，再把输出还原为词级评估；不明确这个约定，指标就不可比。

## 细读预训练监督与下游标签

遮住目标只是避免直接复制的一种办法，随机替换和保留原词使输入中的每个可见词都可能是待预测位置。模型不能简单地把所有未出现遮罩符号的位置当作绝对可信。与此同时，预测任务的选择仍由训练程序控制，所以标签张量应显式区分被选位置和忽略位置，不能只根据输入是否等于遮罩符号反推标签。

句对任务的段落标记与注意力掩码也不是一回事。段落标记告诉模型某个词属于第一段还是第二段；通常两段之间仍可相互注意。若错误地把两段完全隔离，跨句关系所需的信息交互会被阻断。序列中的分隔符提供边界，但不会自动替代所有下游任务的结构编码。

抽取式问答进一步说明任务头的重要性。起点和终点各得到一个位置分布，解码还需要限制起点不晚于终点、答案跨度不超过约定长度，并处理不可回答问题的协议。两个分布各自最大的位置可能形成非法跨度，不能无条件分别取最大值后拼接。模型表示与任务解码必须作为一条完整管线检查。

对于词级序列标注，一个原词可能被切成多个子词。只监督首子词与监督所有子词都可以定义成合理任务，但它们造成的损失权重不同：长词若有更多子词，就可能受到更多次监督。评价时还要还原到原始词边界。这个问题不是分词器的小细节，而是监督单位与评价单位是否一致的问题。

一个适合教学的对照是固定同一短文本，分别查看未损坏输入、遮罩输入和随机替换输入的标签位置；随后把同一编码器接分类头与问答头，比较输出形状。若学生能够指出哪一步仍沿用预训练参数、哪一步更换了监督目标，就真正理解了迁移。仅能描述双向注意力，却无法说明损失算在哪些位置，仍不足以正确实现微调。

## 自测与答案

1. **15% 等于 MASK token 的比例吗？** 不等，15% 是预测位置比例；按原始规则实际替换为 MASK 的约为全部 token 的 12%。
2. **BERT 分类时需要遮住一个词吗？** 通常不需要，任务头从编码器表示预测类别。
3. **为什么不能仅用原表 5 证明 NSP 永远必要？** 数据、训练预算、负例生成和模型规模限定了该消融结论，其他设置必须另行实验。
