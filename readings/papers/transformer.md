# Transformer：从一次注意力计算走到完整编解码器

> Ashish Vaswani 等，*Attention Is All You Need*，NeurIPS 2017；核对 [arXiv v1 全文](https://arxiv.org/pdf/1706.03762v1)。先修：[A02 张量](../../docs/01-foundations/a-math-statistics-optimization.md#a02)、[D10 残差](../../docs/01-foundations/d-deep-learning.md#d10)、[F06 序列到序列](../../docs/02-perception-language/f-nlp-transformers-llms.md#f06)。

## 原论文究竟替换了什么

论文面向机器翻译，提出由注意力与逐位置前馈网络构成的编码器—解码器。它减少训练时因循环状态带来的串行依赖，但自回归生成目标句时仍需逐步输出 token。把 Transformer 等同于今天的 decoder-only 聊天模型，会漏掉原文的编码器、交叉注意力与翻译实验。

阅读顺序建议为图 1 → §3.2 注意力 → §3.5 位置信息 → §5 训练 → 表 3 消融。首先辨认三个注意力位置：编码器自注意力、解码器因果自注意力、解码器查询编码器输出的交叉注意力。

## 符号与形状

单头输入 $Q\in\mathbb R^{n_q\times d_k}$、$K\in\mathbb R^{n_k\times d_k}$、$V\in\mathbb R^{n_k\times d_v}$，忽略 batch 维：

$$A=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}+M\right),\quad O=AV.$$

得分和权重形状都是 $n_q\times n_k$，输出是 $n_q\times d_v$。softmax 沿 key 轴逐行归一化。$M$ 对允许位置取 0，对不允许位置取 $-\infty$。缩放来源可用独立零均值单位方差分量理解：点积方差随 $d_k$ 增长，除以平方根使 logit 尺度更稳定。

多头先用各自的投影生成 $Q_i,K_i,V_i$，拼接各头结果，再投影回模型宽度。头数增加时通常相应减小每头宽度，不是免费复制完整模型。前馈层 $\mathrm{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2$ 对每个位置独立作用；位置间的信息交换由注意力承担。

原文使用正弦余弦位置编码，与输入 embedding 相加。没有位置相关机制时，自注意力对输入排列有相应的等变性，不能只凭 token 集合区分词序。

## 两个 token 的完整计算

教学取 $d_k=1$，$Q=K=[1,2]^\top$，$V=[10,20]^\top$。无掩码得分矩阵为 $\begin{bmatrix}1&2\\2&4\end{bmatrix}$。第一行 softmax 约为 $(0.26894,0.73106)$，输出 $17.3106$；第二行约为 $(0.11920,0.88080)$，输出 $18.8080$。

加入因果掩码后，第一行第二列为 $-\infty$，所以第一位置输出变为 10；第二行仍为 18.8080。这个例子说明因果掩码禁止读取未来，且必须加在 softmax **之前**。若先 softmax 再把未来权重乘零却不重新归一化，第一行权重和就不是 1，计算语义发生改变。

若第二个 token 的值向量为二维 $(20,5)$，输出也变为二维，但注意力权重仍只由 $Q,K$ 决定。查询/键决定“取哪些位置”，值决定“取回什么内容”；这比把三者统称为 embedding 更清楚。

## 训练与生成为什么不同

训练输入真实目标序列的右移版本，使用因果掩码同时预测各位置下一 token，交叉熵沿有效标签位置求和或平均。并行并不导致标签泄漏，因为目标位置不可读取自己要预测的未来 token。

生成时先计算源序列编码，再逐 token 扩展目标；历史 K/V 可以缓存，以免重复计算投影。KV cache 是实现关联知识，不应写成这篇论文的主要新贡献。beam search、长度惩罚、label smoothing、学习率 warmup 等训练和解码细节会共同影响结果。

## 从一个头看懂完整计算图

注意力和前馈层处理两种不同的混合。注意力沿位置维聚合信息，前馈层沿特征维重新组合信息；残差让原表示与更新并存，归一化控制数值尺度。若只保留注意力而删除前馈，并不能简单理解为“仍保留全部智能，只少一点参数”，因为特征空间中的非线性变换也被改变。阅读一层源码时应按这四种功能标注，而不是仅记模块名字。

交叉注意力尤其适合练习形状推导。假设目标句有五个位置、源句有七个位置，单头得分矩阵就是五乘七。每个目标位置决定从七个源位置读回多少信息；源句长度不会因为目标句变长而跟着增加。解码器下一层的隐藏宽度仍由输出投影控制，不由源长度控制。这能避免把序列长度和特征宽度混为一谈。

训练标签右移也可以直接用三词句子验证。输入是起始符、甲、乙，标签是甲、乙、结束符。第三个输入位置可以看到起始符、甲、乙，预测结束；第二个输入位置不能看到乙对应的未来输入位置。一次前向同时算三项损失，只是共享矩阵运算，因果依赖并没有被取消。

另外，填充掩码和因果掩码解决不同问题。填充掩码排除没有真实内容的补齐位置；因果掩码排除时间上的未来。一个位置可同时受两者约束。若批中序列长短不同，只加因果掩码仍可能让模型读到填充位置；只加填充掩码则会泄漏未来。两种掩码的形状还要正确广播到批与头的维度。

在数值稳定方面，常用减去每行最大值再求指数来计算softmax。这个操作不会改变数学概率，因为分子分母同时乘同一因子；但它可避免大正数指数溢出。整行都被遮住时不能盲目套用普通公式，需要约定合法行为。注意力实现中许多难查的问题来自这些边界，而非主要矩阵乘法本身。

## 自测与答案

1. **交叉注意力中 Q 与 K 必须等长吗？** 不必，目标长度和源长度可以不同，只需 Q、K 的末维相同。
2. **并行训练为什么仍能生成因果序列？** 因果掩码使位置 t 的预测只依赖允许的前缀，参数共享不等于读取未来。
3. **注意力权重能直接解释模型所有决策吗？** 不能；值投影、多头混合、残差与后续非线性也决定最终输出。
