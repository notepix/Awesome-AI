# 02 · 感知与语言

[← 返回学习地图](../README.md)

本层覆盖视觉表征、自然语言处理、Transformer/LLM、生成模型，以及把视觉与语言连接起来的 VLM。默认先修是基础层中的 D；H 还依赖 E 与 F。

## 推荐顺序

1. 先学习 [E. 计算机视觉](e-computer-vision.md) 与 [F. NLP、Transformer 与 LLM](f-nlp-transformers-llms.md)，两章可以并行。
2. 学习 [G. 生成模型](g-generative-models.md)，理解自回归、VAE、GAN、扩散与流模型。
3. 在视觉和语言主干通过检测后进入 [H. VLM 与多模态](h-multimodal-vlm.md)。

## 完成标准

能说明 CNN、ViT 与 Transformer 的数据流和张量形状；能实现小型分类器或 Mini-Transformer；能比较至少两类生成目标；能完成图文检索或零样本分类实验，并报告基线、消融、错误样本与适用边界。
