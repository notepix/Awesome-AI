# 06 · 项目与验收

[← 返回学习地图](../README.md)

本层用项目检验能否把知识点连接成完整工作流，覆盖基础诊断、经典 ML、深度学习、CV、NLP/LLM、生成模型、VLM、强化学习、RAG/Agent 和综合研究项目。

## 推荐顺序

1. 所有人先完成 [S01 两周基础诊断](s-projects-assessment.md#s01-两周基础诊断)。
2. 完成共同主干后做 S02–S03。
3. 按方向选择 S04–S09，不要求全部同时完成。
4. 最后完成 S10，并使用 S11 统一评分表验收。

## 完成标准

每个项目都具备朴素基线、可复现训练、一项受控改进、消融、错误分析和复现说明；测试集只在最终阶段使用；代码、配置、随机种子、环境和失败案例足以让他人在干净环境复核结果。
