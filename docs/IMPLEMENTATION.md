分章和系统串讲是讲义正文来源；精读正文独立维护，完整版收录精读导航。`curriculum.json`管理讲义顺序和知识点归属，`readings/catalog.json`管理论文/源码到知识点的关系。生成脚本建立知识单元反向链接、术语索引和单文件完整版，不固定未来知识点数量，也不要求每单元恰好一个代码块。

```text
python scripts/sync_navigation.py
python scripts/build_full.py
python scripts/sync_navigation.py --check
python scripts/build_full.py --check
python scripts/validate_content.py
python -m unittest discover -s scripts/tests -v
```

两个 `--check` 均逐字比较生成文本，不进行哈希值校验。修改正文后需要重新生成，不要手改完整版或索引自动区。知识点标题可改，旧锚点需保留；本轮原有标题未改。

## 资料与源码的证据范围

课程与教材索引记录固定年份或在线版本、具体章节/讲次、公开程度和核验日期，见[资源映射](07-resources/t-source-index.md#t04-课程教材与本仓库的对应关系)。它是定位与教学取舍依据，不声称逐页阅读所有教材和看完全部视频。新增内容以原始论文、作者教材和官方课程为来源，并用原创例子解释。

源码导读实际阅读固定版本的关键文件，不以README作为源码行为的唯一依据。阅读版本为 Transformers v4.57.1、PEFT v0.17.1、TRL v0.24.0、vLLM v0.11.0、LangGraph 0.6.7；它们是教学阅读版本，不声称为最新发布。nanoGPT明确标为已弃用的经典实现，保存带日期的实际阅读文件与MIT许可，快照不声称是原子发布版本。

论文实验为作者报告，手算和伪代码为教学解释，本地小实验另行记录。没有逐篇复现原论文大规模训练，没有运行六个上游项目的训练或部署套件。独立审阅覆盖八篇串讲的关键公式/例子，并抽查DPO、DeepSeekMath、RAG；发现的标签移位前提和章节定位问题已修正。

## 实际运行与剩余边界

五条离线实践线已在本机Python3.12、CPU环境运行：26项算法与边界测试通过，30个命令阶段退出码为0；独立审查发现并修复边界问题后，9个受影响阶段复测也全部通过。实际版本、命令、指标和修复说明见[完整记录](../labs/VALIDATION.md)。这验证流程和所列算法性质，不等于模型质量达标。例如Mini-GPT续训后验证困惑度由333.87升至418.75；文档保留这一结果用于说明过拟合与分布差异。

Qwen、MiniLM、CLIP扩展已实现，用户权重尚未提供；真实权重加载、CUDA执行和显存峰值没有运行。缺模型时返回明确错误的路径已经运行，但不把它记为模型验证通过。8GB显存、16GB内存是目标配置，不能当作实测资源保证。

文档工具检查包括旧完整版首页锚点兼容性、章节归属、先修引用与环路、本地文件和锚点、公式定界符、Python代码语法与生成文本同步。外部来源是人工重点核验，自动检查不声称所有远程网址永久有效。CI已配置文档和CPU算法检查，其远程运行结果需以后续平台执行为准。

最终本地核对：9项文档工具测试通过；90份Markdown的内容检查通过；导航和完整版均与生成文本逐字一致。直接比较重构前后文本，21章原知识点标题与顺序全部保留，旧完整版的全部标题锚点仍可用。未进行哈希值校验。
