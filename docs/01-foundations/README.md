# 01 · 基础层

[← 返回学习地图](../README.md)

本层建立所有现代 AI 方向共用的语言：数学与概率、可复现实验、经典搜索与规划、传统机器学习、概率模型，以及深度学习训练机制。

## 推荐顺序

1. 交替学习 [A. 数学、统计与优化](a-math-statistics-optimization.md) 与 [B. 编程、数据与实验基础](b-programming-data-experiments.md)。
2. 学习 [C. 传统机器学习](c-machine-learning.md)，把数学目标、数据流程和评估连接起来。
3. 进入 [D. 深度学习共同主干](d-deep-learning.md)。
4. [B+. 经典人工智能](b-plus-classical-ai.md) 可在 B 后学习；机器人、规划或 Agent 方向应完成。
5. [C+. 概率模型与无梯度优化](c-plus-probabilistic-black-box.md) 可在 C 后学习；概率建模、贝叶斯优化方向应完成。

## 完成标准

能解释常用公式和张量形状；能识别数据泄漏并建立可复现实验；能从零实现至少一个搜索算法、线性/逻辑回归和 MLP 训练循环；能用基线、验证集、错误分析和失败条件说明模型结论。
