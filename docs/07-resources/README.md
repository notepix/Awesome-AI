# 07 · 资料索引

## 推荐顺序

学习某个知识点时先使用该单元的“资料定位”；需要核验出处、选择同主题资料或判断前沿信息是否过时时，再查阅 [T. 总索引与资料使用说明](t-source-index.md)。
