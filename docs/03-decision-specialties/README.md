# 03 · 决策与专业分支

[← 返回学习地图](../README.md)

本层汇集决策学习和六个专业方向。它不是一条必须全部顺序学习的主线：完成基础层后，按研究或项目目标选择对应分支。

## 推荐顺序

- 决策与控制：先学 [I. 强化学习](i-reinforcement-learning.md)。
- 结构化、语音或序列数据：分别进入 [J. 图神经网络](j-graph-neural-networks.md)、[K. 语音与音频](k-speech-audio.md) 或 [L. 时间序列](l-time-series.md)。
- 数据科学与因果：建议 `C/C+ → L → M`，进入 [M. 因果推断](m-causal-inference.md)。
- 推荐、搜索与 RAG：建议 `C/D → F → N`，进入 [N. 推荐、搜索与检索](n-recommendation-search-retrieval.md)。

## 完成标准

所选分支的“分支”单元全部通过检测；能建立朴素基线，选择符合任务的指标，完成一个端到端小项目；能指出数据假设、离线评估与真实部署之间至少一个差距。
